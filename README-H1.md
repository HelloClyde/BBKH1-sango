# 三国霸业 H1 原生横屏版

> 工作区开发候选 `0.2.3-h1-ui` 加入 GPT Image 金色题字、四张历史时期插图和 33 张君主肖像。素材更新已通过离线 MIPS 绘制检查。此前战略拖动通过 H1 实机验证，战斗拖动通过离线 MIPS 检查。下文发布版本记录为 0.2.2。

版本：0.2.2-h1-savepath。目标：步步高 H1 / Y100 **V1.41，480×272**。

基于 HelloClyde/BBK9588-sango 的 `8786793bd9c7c102b05b72cd9d88887d100ac60d`。H1 入口、状态区、文件系统、图形、输入和 PCM 音频已适配。

## 安装

解压 `dist/h1/H1Sango-install.zip`，把其中的“应用”文件夹合并到设备存储根目录。新版程序和素材须一起更新，尤其是新增的 `sango.h1r`。退出 USB 磁盘模式后，从桌面游戏分类打开《三国霸业》。

```text
应用/程序/H1Sango.bda
应用/数据/游戏/sango.lib
应用/数据/游戏/sango.clr
应用/数据/游戏/sango.h1r
应用/数据/游戏/sango.h1p
应用/数据/游戏/SGMUSIC/menu.wav
应用/数据/游戏/SGMUSIC/strategy.wav
应用/数据/游戏/SGMUSIC/battle.wav
```

不需要复制源码或私有模拟器文件，安装包不含固件。

## 布局与文字

- 主菜单使用重新生成的横屏木雕场景；剧本页为四张横向卡片。
- 君主页为名单、势力图和君主预览三栏；设置、制作群组、城池信息、武将表格、数量输入和三槽存读档均按 480×272 重排。
- 正文、按钮 14 像素，页面标题 24 像素（12px 点阵整数放大），主菜单烘焙标题 24 像素。修复了点阵字形下沿笔画被裁掉的问题。所有汉字按同一字号与共同基线导出，不再逐字缩小；底部提示统一使用 12px。
- 战略地图显示 12×6 格，底部放状态和操作按钮；可上下拖动查看 12×9 的世界。
- 战场显示 20×9 格，每格显示为 24×24 像素，底栏重新排版。移动、技能规则仍使用原 15×15 窗口。

横屏底图由内置 image_gen 生成，再在目标尺寸排字。母图、提示词和 PNG 在 `assets/h1-landscape/`，素材包为 `dist/h1/H1Sango-landscape-assets.zip`。

方向键选择 / 移动，确定 / Enter / 空格执行，返回 / Esc 取消。也可直接触摸菜单、人物、城池和按钮。地图支持拖动；原生菜单在松手位置确认，避免坐标延迟把点击误判为拖动。

存档位于 `A:\应用\数据\游戏\`，文件名为 `sango0.sav` 至 `sango5.sav`，保留原三槽双文件格式，安装包不覆盖存档。0.2.1 的旧存档需从旧目录按原名成对移入。设置文件为同目录内的 `sango.cfg`。

## 构建

依赖子模块 `sdk/`（本次 `067fe072477861dfc8949d7b1a55279fb92d2548`）、`.toolchain/bin`、Python 和 Pillow。已有字体与素材可直接编码构建，无需图像生成服务。

```powershell
python h1/build_h1.py
python h1/test_landscape.py
python h1/render_battle_fixture.py
```

重新排字用 `h1/prepare_landscape.py`，重新编码字体用 `h1/make_font.py`，读取 `assets/fonts/` 中的原生 BDF 和马善政毛笔楷书。上游 LIB / CLR 素材改动时，构建加 `--assets`。战场地形由原始 16×16 帧生成 24×24 帧。兵种和战船使用 GPT Image 高清重绘，按各帧原来的位置和尺寸缩至 24×24 网格，并保留透明边缘。`sango.h1p` 配套提供四个剧本经 SeedVR2 超分的 72×72 武将头像，按需从游戏目录读取。完整固件验证需要匹配的 QEMU、内核和 NAND。

原上游代码保留在 `src/` 与 `include/`；适配在 `h1/`，生成文件在 `build/h1/`。原 `README.md` 介绍 9588 版本，本 H1 版以本文件为准。
